# ユーザーマニュアル

このディレクトリには、WannaV 生徒様特典自動送付システムのユーザーマニュアルが含まれています。

## ファイル一覧

- `USER_MANUAL.md` - Markdown形式のマニュアル
- `USER_MANUAL.html` - HTML形式のマニュアル（PDF変換用）

## PDFへの変換方法

### 方法1: ブラウザから直接印刷（推奨）

1. `USER_MANUAL.html` をブラウザで開く
2. ブラウザの印刷機能を使用（Ctrl+P または Cmd+P）
3. 送信先を「PDFに保存」に変更
4. 印刷設定:
   - レイアウト: 縦
   - 余白: デフォルト
   - 背景のグラフィック: ✅ オン
   - ページ範囲: すべて
5. 「保存」をクリック

### 方法2: Chrome DevTools（高品質）

1. Google Chromeで `USER_MANUAL.html` を開く
2. F12キーでDevToolsを開く
3. Ctrl+Shift+P（Cmd+Shift+P on Mac）でコマンドパレットを開く
4. "PDF" と入力して「Print to PDF」を選択
5. PDFが自動的にダウンロードされます

### 方法3: オンラインツール

以下のようなオンラインツールを使用してHTMLをPDFに変換できます:
- https://www.sejda.com/html-to-pdf
- https://pdfcrowd.com/html-to-pdf/
- https://cloudconvert.com/html-to-pdf
