# 🔍 管理画面にログが表示されない問題のトラブルシューティング

## 📋 問題の概要

マイグレーション実行後も管理画面に送信ログが表示されない場合の診断と解決方法をまとめています。

---

## 🧪 診断手順

### ステップ1: データベースの状態を確認

Render のShellで以下のコマンドを実行してください：

```bash
npm run check:db
```

**確認するポイント:**
- ✅ `send_logs` テーブルに件数があるか
- ✅ `pending_benefit_rank` と `pending_since` カラムが存在するか
- ✅ 最新のログが表示されるか

---

### ステップ2: ログ保存機能をテスト

以下のコマンドでテストログを作成します：

```bash
npm run test:log
```

その後、再度データベースを確認：

```bash
npm run check:db
```

**期待される結果:**
- `send_logs` テーブルに「テスト太郎」のログが追加される
- 管理画面をリロードすると表示される

---

## 🔍 考えられる原因と対処法

### 原因1: バッチ処理がまだ実行されていない

**確認方法:**
- 管理画面の「送信履歴」セクションが空 → バッチ未実行の可能性大

**対処法:**
1. 管理画面で「▶️ 手動実行」ボタンをクリック
2. バッチ処理を実行
3. 完了後、ページをリロード

---

### 原因2: データベース接続エラー

**確認方法:**
```bash
npm run check:db
```

エラーメッセージが表示される場合：

**対処法:**
1. Renderダッシュボードで環境変数を確認
   - `DATABASE_URL` が正しく設定されているか
2. PostgreSQL データベースが起動しているか確認

---

### 原因3: マイグレーションが正しく実行されていない

**確認方法:**
```bash
npm run check:db
```

`pending_benefit_rank` カラムが表示されない場合：

**対処法:**
1. マイグレーションを再実行：
   ```bash
   npm run migrate
   ```

2. 確認：
   ```bash
   npm run check:db
   ```

---

### 原因4: ブラウザのキャッシュ

**対処法:**
1. ブラウザで強制リロード
   - Windows/Linux: `Ctrl + Shift + R`
   - Mac: `Cmd + Shift + R`

2. またはシークレットモードで管理画面を開く

---

### 原因5: Renderの自動デプロイが完了していない

**確認方法:**
1. Render ダッシュボード → Events タブ
2. 最新のデプロイが「Live」になっているか確認

**対処法:**
- デプロイが完了するまで待つ（通常1〜3分）
- 完了後、管理画面をリロード

---

## 📞 それでも解決しない場合

以下の情報を提供してください：

1. **`npm run check:db` の出力結果**（全文）
2. **`npm run test:log` の出力結果**（全文）
3. **管理画面のスクリーンショット**

## 🔧 よくある質問

### Q1: `send_logs` が0件のままです

**A:** バッチ処理がまだ実行されていません。管理画面で「▶️ 手動実行」をクリックしてください。

---

### Q2: `npm run check:db` でエラーが出ます

**A:** 環境変数 `DATABASE_URL` が正しく設定されているか確認してください。

Render ダッシュボード → Environment → `DATABASE_URL`

---

### Q3: テストログは作成されるが、本番ログが作成されません

**A:** バッチ処理でエラーが発生している可能性があります。

1. Render の Logs タブでエラーを確認
2. 特に `createSendLog` や `Discord送信` 関連のエラーをチェック

---

### Q4: 管理画面に「まだ送信履歴がありません」と表示されます

**A:** 以下を順番に確認：

1. `npm run check:db` で `send_logs` に件数があるか確認
2. ある場合 → ブラウザのキャッシュをクリア
3. ない場合 → バッチ処理を手動実行

---

すべて完了しても表示されない場合は、上記の情報を提供してください。
