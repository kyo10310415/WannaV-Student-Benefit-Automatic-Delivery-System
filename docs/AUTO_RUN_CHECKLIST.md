# 自動実行を有効にする前のチェックリスト

## ✅ 必須確認事項

### 1. 環境変数の設定

Render Dashboard で以下の環境変数が正しく設定されているか確認:

```
ENABLE_CRON=true  ← これを設定
```

### 2. その他の必須環境変数

以下がすべて設定されているか確認:

```
DATABASE_URL=postgresql://...          ✅ 必須
DISCORD_BOT_TOKEN=your_token_here     ✅ 必須
GOOGLE_SERVICE_ACCOUNT_JSON={...}     ✅ 必須
NODE_ENV=production                    ✅ 必須
PORT=3000                              ✅ 必須
```

### 3. データの準備状況

#### スプレッドシート（❶RAW_生徒様情報）
- [ ] A列: 生徒名が入力されている
- [ ] B列: 学籍番号が入力されている
- [ ] C列: プラン種別が「スタンダードプラン」「レギュラープラン」「プレミアムプラン」のいずれか
- [ ] **D列: 会員ステータスが「アクティブ」になっている** ⚠️ 重要
- [ ] G列: DiscordユーザーID（任意）
- [ ] M列: DiscordチャンネルURLが入力されている
- [ ] U列: レッスン開始日が入力されている（YYYY/MM/DD形式）

#### スプレッドシート（❸契約後チェックシート）
- [ ] B列（4行目以降）: 入会日が入力されている

#### スプレッドシート（RAW_支払い状況）
- [ ] ヘッダー（13行目）: 月の形式が「YYYY/M」（例: 2026/1）
- [ ] データ（14行目以降）: C列に学籍番号、各月列に支払い状況
- [ ] **前月の列が「支払い完了」になっている生徒のみ送信されます**

### 4. Discord Botの準備
- [ ] BotがDiscordサーバーに招待されている
- [ ] Botに「Send Messages」権限がある
- [ ] Botに「Attach Files」権限がある
- [ ] 各生徒のチャンネルでBotがメッセージを送信できる

### 5. 10日達成報酬送信済み生徒の登録
- [ ] `npm run register:10day` を実行済み（既存生徒がいる場合）

### 6. テスト実行の確認
- [ ] 管理画面で「▶️ 手動実行」をテスト実行済み
- [ ] 送信ログでエラーがないことを確認済み
- [ ] Discordで実際にメッセージが届くことを確認済み

## 🚀 有効化手順

### Step 1: Render環境変数を設定

```
1. Renderダッシュボードにログイン
   https://dashboard.render.com/

2. wannav-benefit-system サービスを選択

3. Environment タブを開く

4. 「Add Environment Variable」をクリック

5. 以下を追加:
   Key: ENABLE_CRON
   Value: true

6. 「Save Changes」をクリック
```

### Step 2: サービスの再起動を待つ

環境変数を変更すると、Renderが自動的にサービスを再起動します。

**再起動完了の確認:**
- Dashboard → Events タブ
- 「Deploy succeeded」と表示されるまで待つ（数分）

### Step 3: ログで確認

```
1. Dashboard → Logs タブを開く

2. 以下のログを確認:
   ✅ すべての初期化が完了しました
   ⏰ 定期実行スケジュール設定完了: 毎日17時（日本時間）
   🌐 サーバー起動完了: http://localhost:3000
```

もし以下のログが表示される場合は、まだ無効です:
```
⏸️  定期実行は無効化されています（環境変数 ENABLE_CRON=true で有効化）
```

### Step 4: 管理画面で確認

```
1. 管理画面を開く: https://wannav-benefit-system.onrender.com/

2. システム状態を確認:
   定期実行: ✅ 有効（毎日17時に自動実行）
   
   ※「⏸️ 無効」と表示される場合は、環境変数設定を再確認
```

## ⏰ 自動実行のタイミング

### 実行時刻
- **毎日17時（日本時間）**
- サーバーはUTCで動作しているため、node-cronの`timezone: 'Asia/Tokyo'`で調整

### 初回実行
- 有効化した当日の17時から開始
- 例: 1月29日 15時に有効化 → 同日17時に初回実行

### 実行内容
1. スプレッドシートから生徒情報を取得
2. 各生徒の送信条件をチェック
3. 条件を満たす生徒にDiscordメッセージを送信
4. データベースに履歴を記録

## ⚠️ 注意事項

### 1. 必ずテスト実行してから有効化
自動実行を有効にする前に、必ず「手動実行」でテストしてください。

**理由:**
- 自動実行で想定外のメッセージが大量送信される可能性
- 送信条件の誤設定による誤送信
- データ不備による送信失敗

### 2. 初回実行時の注意
初回実行時は、条件を満たす生徒全員に送信されます。

**確認事項:**
- 会員ステータスが「アクティブ」の生徒数
- 前月の支払いが「支払い完了」の生徒数
- 送信対象ランクの生徒数

### 3. 送信履歴の確認
自動実行後は必ず管理画面で送信履歴を確認してください。

**確認項目:**
- 送信成功件数
- スキップ件数（支払い未完了など）
- 送信失敗件数（エラー）

### 4. ログの監視
初日は特にログを監視してください。

**Render Logs で確認:**
- エラーメッセージがないか
- 送信件数が想定通りか
- 処理時間が正常か

## 🔄 無効化する場合

自動実行を停止したい場合:

```
1. Render Dashboard → Environment タブ

2. ENABLE_CRON の値を false に変更
   または
   ENABLE_CRON を削除

3. Save Changes

4. サービスが再起動されます
```

## 📊 運用開始後の確認項目

### 毎日の確認（推奨）
- [ ] 管理画面で送信履歴を確認
- [ ] エラーがないか確認
- [ ] Discordで実際にメッセージが届いているか確認

### 毎週の確認
- [ ] 送信スキップが多い場合、支払い状況を確認
- [ ] スプレッドシートのデータ整合性を確認

### 毎月の確認
- [ ] 月初の送信が正常に行われているか確認
- [ ] 新規生徒の登録を確認

## 🎯 トラブルシューティング

### Q: 自動実行されない
**確認:**
1. 環境変数 `ENABLE_CRON=true` が設定されているか
2. サービスが再起動されたか
3. ログに「定期実行スケジュール設定完了」と表示されているか

### Q: 送信されない生徒がいる
**確認:**
1. 会員ステータスが「アクティブ」か
2. プラン種別が対象プランか
3. 支払い状況が「支払い完了」か（月次ランクの場合）
4. タイミング条件を満たしているか

### Q: エラーが発生する
**確認:**
1. Discord Bot Tokenが正しいか
2. Google Service Account JSONが正しいか
3. スプレッドシートの共有権限があるか
4. データベース接続が正常か

## 📝 チェックリスト完了確認

すべての項目を確認したら、以下にチェックを入れてください:

- [ ] すべての環境変数が設定されている
- [ ] スプレッドシートのデータが正しい
- [ ] Discord Botの権限が設定されている
- [ ] 10日達成済み生徒を登録した（該当する場合）
- [ ] テスト実行で正常に動作することを確認した
- [ ] 自動実行を有効化する準備ができた

✅ すべてにチェックが入ったら、`ENABLE_CRON=true` に設定してください！
